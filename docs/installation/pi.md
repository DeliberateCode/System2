# Pi publication status

The Pi channel is **not published**. No npm installation command is available, and the
package name must not be treated as currently installable.

## Current scope

The canonical package template describes a compiler-generated **base workflow**: the 13
roles, an in-session `/delegate` role switch, prompts, and a Pi extension for safety gates.
It does not provide the Claude Code overlay/profile commands.

The source compiler can project overlay compositions for Pi, but that is a developer path
from a repository checkout rather than end-user package UX. Pi loader and synthetic
pre-execution blocking tests provide evidence for the extension mechanism; they do not make
an unpublished package available.

## Updating and removal

Not applicable until publication. Installation, updating, and removal instructions will be
added only after the package is published and release provenance is recorded.
